# 接口说明文档 — 第二手 SecondHand AI 后端

> 作者：田博 · 版本 V0.5 · 基础路径 `http://localhost:8080` · 前缀 `/api`
> 本机无网/无 MySQL 时可用 MockAiService 联调（`ai.enabled=false` 默认）。

## 0. 通用约定

- 统一返回体：

```json
{ "code": 200, "message": "操作成功", "data": { } }
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/登录过期 |
| 403 | 无权操作 |
| 404 | 资源不存在 |
| 409 | 状态冲突 |
| 500 | 服务器错误 |
| 1001~1007 | 用户/商品/分类/收藏业务错误 |
| 1101~1104 | AI 业务错误 |

- 当前用户：请求头 `X-User-Id`（登录模块接入前用此头；不传默认用户 1=田博）。
- 分页返回：

```json
{ "records": [], "total": 0, "page": 1, "size": 10, "pages": 0 }
```

## 1. 商品接口 `/api/products`

### 1.1 发布商品 `POST /api/products`

请求体：

```json
{
  "categoryId": 11,
  "title": "iPhone 13 128G 九成新",
  "description": "自用一年，无拆修",
  "price": 2800,
  "conditionLevel": 9,
  "conditionDesc": "九成新，轻微使用痕迹",
  "tags": "手机,苹果",
  "location": "下沙校区",
  "coverImage": "http://img/cover.jpg",
  "images": ["http://img/1.jpg", "http://img/2.jpg"],
  "estimatedPrice": 2700,
  "publishNow": true
}
```

- `publishNow=true` 直接上架(1)，`false` 存草稿(0)
- 返回：`data = 商品ID`

### 1.2 编辑商品 `PUT /api/products/{id}`

仅本人；已售出不可编辑；`images` 传则整体替换。请求体同 1.1（可只传修改字段）。

### 1.3 上架/下架 `PUT /api/products/{id}/status`

```json
{ "status": 1 }
```

- `1`=上架（草稿/已下架/审核驳回可上架），`2`=下架（在售/审核中可下架）

### 1.4 删除商品 `DELETE /api/products/{id}`

仅本人；已售出不可删除；逻辑删除。

### 1.5 分页浏览/检索 `GET /api/products`

Query 参数：

| 参数 | 说明 |
|------|------|
| keyword | 关键词（标题/描述 LIKE，FULLTEXT 索引已建） |
| categoryId | 分类 ID |
| minPrice / maxPrice | 价格区间 |
| conditionLevel | 成色下限 1~10 |
| sortBy | 1最新(默认) 2价格升 3价格降 4浏览量最多 |
| page / size | 页码(1起) / 每页(1~100) |

返回：`PageResult<ProductListItemVO>`

### 1.6 商品详情 `GET /api/products/{id}`

- 浏览量 +1；记录浏览足迹；返回是否已收藏。
- 非在售商品仅本人可见。

返回：`ProductVO`（含 sellerNickname、sellerCredit、categoryName、images、favorited）

### 1.7 我的商品 `GET /api/products/mine?status=&page=&size=`

### 1.8 猜你喜欢 `GET /api/products/recommend?limit=10`

基于浏览/收藏分类偏好推荐在售商品（排除已浏览/已收藏）。

## 3. AI 估价 `/api/ai/estimate`

### `POST /api/ai/estimate`

```json
{
  "categoryId": 11,
  "description": "iPhone 13 128G 使用两年，九成新",
  "conditionLevel": 9,
  "ageMonths": 24,
  "useLlm": false
}
```

- 估价公式：`推荐价 = 分类基准价 × 成色系数 × (1-折旧率)^(月/12) × 热度系数`
- `useLlm=true` 且 `ai.enabled=true` 时大模型加权补充（权重 0.4）
- 每次估价写入 `ai_estimate_log`（可审计）

返回：

```json
{
  "min": 2900,
  "recommend": 3220,
  "max": 3540,
  "detail": { "basePrice": "3000", "conditionScore": 9, "conditionFactor": "0.88", "ageMonths": 24, "ageFactor": "0.6724", "heatFactor": "1.3", "formula": "..." },
  "source": 1
}
```

## 4. AI 自动填表发布 `/api/ai`

### 4.1 生成草稿 `POST /api/ai/draft`

```json
{
  "images": ["http://img/a.jpg"],
  "hint": "iPhone 13 用了两年 九成新 屏幕有贴膜",
  "expectPrice": 2500
}
```

链路：识别（Mock 关键词 / 真实大模型）→ 分类匹配 → 规则引擎估价 → 写入 `ai_publish_draft`（待确认）。

返回：`AiDraftVO`（draftId、categoryName、title、description、conditionLevel、suggestPrice、minPrice、maxPrice、images、status=0）

### 4.2 一键发布 `POST /api/ai/publish`

```json
{ "draftId": 1, "title": "（可选覆盖标题）", "price": 2400 }
```

- 校验草稿归属与状态（仅待确认可发布，幂等防重）
- 创建商品：`ai.audit-on-publish=true`（默认）进入审核中(4)，`false` 直接上架(1)
- 草稿状态更新为已发布并关联 productId

返回：`ProductVO`

## 5. 快速联调示例（curl）

```bash
# 发布商品
curl -X POST http://localhost:8080/api/products \
  -H "Content-Type: application/json" -H "X-User-Id: 1" \
  -d '{"categoryId":11,"title":"测试手机","price":1000,"publishNow":true}'

# 分页检索
curl "http://localhost:8080/api/products?keyword=手机&page=1&size=10"

# AI 估价
curl -X POST http://localhost:8080/api/ai/estimate \
  -H "Content-Type: application/json" -H "X-User-Id: 1" \
  -d '{"categoryId":11,"conditionLevel":9,"ageMonths":12}'

# AI 自动填表
curl -X POST http://localhost:8080/api/ai/draft \
  -H "Content-Type: application/json" -H "X-User-Id: 1" \
  -d '{"hint":"iPad 九成新"}'
```

## 6. 配置项

| 配置 | 默认 | 说明 |
|------|------|------|
| `ai.enabled` | false | 是否启用大模型（false 走 Mock） |
| `ai.llm.base-url / api-key / model` | — | 大模型端点（陈思瀚接入后填写） |
| `ai.audit-on-publish` | true | AI 发布是否进入审核 |
| `cors.allowed-origins` | localhost:5173 等 | 前端跨域白名单 |
