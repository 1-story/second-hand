## 7. AI 估价规则引擎（T3）设计

- 纯 Java 实现，**零第三方依赖**，独立包 `ai.rules`，可单测可复用。
- 估价公式：
  `估价 = 分类基准价 × 成色系数 × 年限衰减系数 × 市场热度系数 × 描述质量系数（可选）`
- 参数来源：`category` 表字段（基准价、年限折旧率、热度权重）+ 规则配置常量。
- 输出：估价区间（最低/推荐/最高）+ 各项系数明细（可解释、可审计），写入 `ai_estimate_log`。

## 8. AI 自动填表发布链路（T4）设计

`图片/描述输入 → AiService（接口，Mock/真实大模型可切换）→ 提取品类+成色+标题+描述 → 规则引擎估价 → 生成草稿(ai_publish_draft) → 用户确认 → 一键发布(product)`

- `AiService` 为接口封装：`estimate()/generateDescription()/recognize()`，当前提供 **Mock 实现**（离线可用），待陈思瀚大模型 API 就绪后切换真实实现（HTTP 调用，接口不变）。
- 发布链路保证：草稿幂等、状态流转、失败可重试。
