# 接口说明文档 — 第二手 SecondHand AI 后端

> 作者：田博 · 版本 V1.0 · **已对齐《接口约定规范 v1.0》（陈思瀚制定）**
> 基础路径 `http://localhost:8080` · 统一前缀 `/api`

## 0. 通用约定（对齐规范第 1~4 节）

- 统一返回体：`{ "code": 0, "message": "success", "data": { } }`；**code=0 成功**，失败为业务错误码；无数据 `data: null`
- 分页：`{ "list": [], "total": 128, "page": 1, "pageSize": 10 }`，参数 `?page=1&pageSize=10`（pageSize 默认 10，最大 100）
- 金额：**整数「分」**（前端展示除以 100）；数据库内部 DECIMAL 元由后端转换
- 时间：`yyyy-MM-dd HH:mm:ss`（Jackson 全局配置）
- 认证：`Authorization: Bearer <token>`（JWT，登录模块接入后生效）；开发期兼容 `X-User-Id` 头（默认用户 1）
- 图片：AI 接口传 base64（含 `data:image/...;base64,` 前缀，单张 ≤5MB）

### 错误码（对齐规范第 3 节，节选常用）

| code | HTTP | 说明 |
|------|------|------|
| 0 | 200 | 成功 |
| 40000 | 400 | 参数错误（含 40001~40012 细分） |
| 40100~40103 | 401 | 认证错误（未登录/Token 失效/账号密码错误/禁用） |
| 40300~40302 | 403 | 无权限/未实名/信用分不足 |
| 40400~40402 | 404 | 资源不存在/商品不存在/订单不存在 |
| 42900~42901 | 429 | 限流/AI 繁忙 |
| 50000~50003 | 500 | 服务端/数据库/AI 降级/图片解析失败 |
| 50400 | 504 | 超时 |

## 1. 商品接口 `/api/products`（金额单位：分）

### 1.1 发布商品 `POST /api/products`（需登录）

```json
{
  "categoryId": 11,
  "title": "iPhone 13 128G 九成新",
  "description": "自用一年，无拆修",
  "price": 280000,
  "conditionLevel": 9,
  "conditionDesc": "九成新，轻微使用痕迹",
  "tags": "手机,苹果",
  "location": "下沙校区",
  "coverImage": "http://img/cover.jpg",
  "images": ["http://img/1.jpg"],
  "estimatedPrice": 270000,
  "publishNow": true
}
```

- `price`/`estimatedPrice` 单位分；`publishNow=true` 上架(1)，`false` 草稿(0)
- 返回：`data = 商品ID`

### 1.2 编辑 `PUT /api/products/{id}` / 上下架 `PUT /api/products/{id}/status` / 删除 `DELETE /api/products/{id}`

- 上下架 body `{ "status": 1 }`（1 上架 / 2 下架）；仅本人，已售出不可编辑/删除

### 1.3 分页浏览/检索 `GET /api/products`（免登录，只读）

参数：`keyword / categoryId / minPrice / maxPrice / conditionLevel / sortBy(1最新 2价格升 3价格降 4浏览量) / page / pageSize`

### 1.4 详情 `GET /api/products/{id}`（免登录，只读）

返回 `ProductVO`：`{ id, sellerId, sellerNickname, sellerCredit, categoryId, categoryName, title, description, price(分), estimatedPrice(分), conditionLevel, conditionDesc, tags, location, coverImage, status, viewCount, favoriteCount, favorited, createdAt, images[] }`

### 1.5 我的商品 `GET /api/products/mine` / 浏览足迹 `GET /api/products/history` / 猜你喜欢 `GET /api/products/recommend`（均需登录）

## 3. AI 接口 `/api/ai`（需登录；engine 字段：llm / rule）

### 3.1 识别 `POST /api/ai/identify`

```json
{ "imageBase64": "data:image/jpeg;base64,...", "hint": "机械键盘" }
```

返回：`{ category: "digital", categoryName: "数码产品", condition: 90, conditionName: "九成新", confidence: 0.85, engine: "rule" }`

- category 枚举：`book / digital / living / sports / clothing / other`；condition：`100/90/80/70`

### 3.2 描述生成 `POST /api/ai/describe`

```json
{ "imageBase64": "data:image/jpeg;base64,...", "category": "digital", "condition": 90, "keywords": ["机械键盘","87键","青轴"] }
```

返回：`{ description: "……", engine: "rule" }`

### 3.3 智能估价 `POST /api/ai/estimate`

```json
{ "originalPrice": 39900, "category": "digital", "condition": 90, "imageBase64": "data:image/jpeg;base64,..." }
```

返回（金额分）：

```json
{
  "suggestPrice": 19900,
  "priceRange": { "min": 16000, "max": 24000 },
  "reason": "原价 399 元，九成新（成色系数约 0.88），结合平台同类商品估价区间 253~309 元，建议售价 281 元。",
  "engine": "rule",
  "detail": { "...": "..." },
  "source": 1
}
```

- 双层架构：规则引擎（原价 × 成色系数 × 年限衰减 × 热度）兜底可用；大模型启用（`ai.enabled=true`）时 engine=llm，失败自动降级 rule（规范 6.3）

### 3.4 自动填表草稿 `POST /api/ai/draft`（内部链路，保留）

```json
{ "images": ["http://img/a.jpg"], "hint": "iPhone 13 用了两年 九成新", "expectPrice": 250000 }
```

返回 `AiDraftVO`：`{ draftId, categoryId, categoryName, title, description, conditionLevel, conditionDesc, suggestPrice(分), minPrice(分), maxPrice(分), images[], status }`

### 3.5 一键发布 `POST /api/ai/publish`

```json
{ "draftId": 1, "title": "可选覆盖标题", "price": 240000 }
```

- 校验草稿归属与状态（幂等）；`ai.audit-on-publish=true` 进入审核中(4)，否则直接上架(1)
- 返回 `ProductVO`

### 3.6 待接入（不属于本模块）

- `POST /api/ai/chat`：AI 智能问答 — 立项分工归 **林天楚**
- `POST /api/ai/review`：AI 辅助审核 — V1.0（管理员）

## 5. 配置项

| 配置 | 默认 | 说明 |
|------|------|------|
| `ai.enabled` | false | 大模型开关（false 走 Mock/规则，engine=rule） |
| `ai.llm.base-url / api-key / model` | — | 大模型端点（陈思瀚接入后填写） |
| `ai.audit-on-publish` | true | AI 发布是否进入审核 |
| `cors.allowed-origins` | localhost:5173 等 | 前端跨域白名单 |
