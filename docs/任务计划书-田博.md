## 7. AI 估价规则引擎（T3）设计

- 纯 Java 实现，**零第三方依赖**，独立包 `ai.rules`，可单测可复用。
- 估价公式：
  `推荐价 = 基准价/原价 × 成色系数 × (1-折旧率)^(使用月数/12) × 市场热度系数；区间 = 推荐价 × [0.90, 1.10]`
- 参数来源：`category` 表字段（基准价、年限折旧率、热度权重），**改价不改代码**（系数校准=改表参数）。
- 输出：估价区间（最低/推荐/最高）+ 各项系数明细（可解释、可审计），写入 `ai_estimate_log`。

## 8. AI 自动填表发布链路（T4）设计

`图片/描述输入 → AiService（接口，Mock/真实大模型可切换）→ 提取品类+成色+标题+描述 → 规则引擎估价 → 生成草稿(ai_publish_draft) → 用户确认 → 一键发布(product)`

- `AiService` 封装：`recognize()/generateDescription()/llmEstimate()/chat()`；Mock（默认，`ai.mock=true`）/ HTTP 骨架（`ai.mock=false`+`ai.enabled=true`）可切换，超时降级返回 null。
- `chat()` 已交付（规范 6.4）：签名 `String chat(Long productId, String question, List<Map<String,String>> history)`，返回 null=不可用，降级文案由 /api/ai/chat 接口层（林天楚）组装。
- 发布链路保证：草稿归属校验、状态流转（待确认→已发布）、幂等防重、AI 辅助审核开关（`ai.audit-on-publish`）。
